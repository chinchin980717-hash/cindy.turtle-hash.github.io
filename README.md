# 盲點輪廓－翻面之前

**實作版本：0.5.0（HTML5／JavaScript 網頁版）**

**文件版次：0.1.4（新增 Gemini 設計提案；未改動遊戲程式）**

直接遊玩：[盲點輪廓](https://chinchin980717-hash.github.io/cindy.turtle-hash.github.io/)

一款純文字、快節奏的認知反轉小遊戲。玩家先看盲點句，在自選時間內留下第一直覺，再翻面閱讀完整情境與盲點解析。

## 遊玩方式

直接打開上方 Pages 網址即可遊玩。首頁可選單人或聚會輪流模式，也能選擇本局題數、題目分類與每題答題時間；時間可選 30、60、90 秒或不計時。聚會模式支援 2–6 人共用一台裝置。每回合可輸入答案、解鎖三層視角提示、鎖定作答，再翻面查看真相。判分提供 0／1／2 分輔助建議，玩家或主持人可手動調整。語音輸入依瀏覽器支援情況提供；不支援語音時仍可用文字作答。

### 線上房間快速用法

線上模式需要至少兩台能上網的裝置。房主選「線上房間實驗版」並按「建立房間」，取得 6 位房間代碼後分享給朋友；其他玩家選「加入房間」，輸入代碼並按「加入房間」。等所有人都顯示已連線後，房主再按「開始這局」。之後每個人在自己的裝置作答，房主負責翻面揭曉與進入下一題。設定頁的玩法說明也附有三項新手 FAQ。完整的操作步驟、訊息格式與技術限制請見 [`docs/peerjs-online-architecture.md`](docs/peerjs-online-architecture.md)。

- `index.html`：Pages 首頁與遊戲畫面。

- `styles.css`：遊戲介面和窄螢幕版面。
- `assets/cover.webp`：首頁響應式遊戲封面；`assets/cover.jpg` 保留原始版本。
- `data/questions.json`：題庫資料。
- `docs/gemini-gameplay-proposal.md`：Gemini 核心玩法規格提案與歷史差異記錄。
- `docs/peerjs-online-architecture.md`：PeerJS 線上房間實驗版的使用與技術說明。
- `CHANGELOG.md`：逐版更新紀錄與驗收範圍。

## 本機預覽

在此資料夾啟動任何靜態 HTTP 伺服器，瀏覽器開啟根目錄即可；不要以 `file://` 直接開啟，因題庫使用 `fetch()` 載入。

## 目前範圍與限制

目前已整合 001–100 共 100 題，分為「日常烏龍」、「職場與校園」、「人際互動」三大類。每回合可選 30、60、90 秒或不計時。除了單人與同裝置輪流模式，也提供使用 PeerJS Cloud 的線上房間實驗版；房主需保持頁面開啟，並將 6 位房間代碼分享給其他玩家。線上版目前不含斷線重連、房主轉移或長期紀錄。關鍵詞只提供判分輔助；替代解釋由玩家或主持人確認。語音輸入是否可用取決於瀏覽器。
