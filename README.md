# 盲點輪廓－翻面之前

**實作版本：0.1.16（HTML5／JavaScript 網頁版）**

**文件版次：0.1.4（新增 Gemini 設計提案；未改動遊戲程式）**

直接遊玩：[盲點輪廓](https://chinchin980717-hash.github.io/cindy.turtle-hash.github.io/)

一款純文字、快節奏的認知反轉小遊戲。玩家先看盲點句，在 30 秒內留下第一直覺，再翻面閱讀完整情境與盲點解析。

## 遊玩方式

直接打開上方 Pages 網址即可遊玩。首頁可選單人或聚會輪流模式，也能選擇本局題數與題目分類；聚會模式支援 2–6 人共用一台裝置。每回合可輸入答案、解鎖三層視角提示、鎖定作答，再翻面查看真相。判分提供 0／1／2 分輔助建議，玩家或主持人可手動調整。語音輸入依瀏覽器支援情況提供；不支援語音時仍可用文字作答。

## 規格文件

- `docs/gemini-gameplay-proposal.md`：使用者提供的 Gemini 核心玩法建議，作為待整合的設計提案；文件明列目前尚未實作的差異。

## 專案結構

- `index.html`：Pages 首頁與遊戲畫面。
- `app.js`：回合流程、倒數、提示、輪流作答、答案揭曉與判分。
- `styles.css`：遊戲介面和窄螢幕版面。
- `assets/cover.webp`：首頁響應式遊戲封面；`assets/cover.jpg` 保留原始版本。
- `data/questions.json`：題庫資料。
- `docs/gemini-gameplay-proposal.md`：Gemini 核心玩法規格提案與歷史差異記錄。
- `CHANGELOG.md`：逐版更新紀錄與驗收範圍。

## 本機預覽

在此資料夾啟動任何靜態 HTTP 伺服器，瀏覽器開啟根目錄即可；不要以 `file://` 直接開啟，因題庫使用 `fetch()` 載入。

## 目前範圍與限制

目前已整合 001–100 共 100 題，分為「日常烏龍」、「職場與校園」、「人際互動」三大類。每回合作答倒數為 30 秒。聚會模式是同一裝置輪流，不含線上多人或搶答。關鍵詞只提供判分輔助；替代解釋由玩家或主持人確認。語音輸入是否可用取決於瀏覽器。Gemini 建議中的搶答模式與其他延伸玩法仍詳見規格提案。
